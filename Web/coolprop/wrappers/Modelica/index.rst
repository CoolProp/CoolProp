.. _Modelica:

****************
Modelica Wrapper
****************

CoolProp is available in Modelica through the ``ExternalMedia`` library, a third-party package that connects external fluid property codes to ``Modelica.Media``-compatible component models.

The latest releases of ``ExternalMedia`` include built-in access to CoolProp, so the CoolProp medium models work out of the box without a separate installation. Releases, the precompiled Modelica library, the manual, and the source code are available from the `ExternalMedia repository <https://github.com/modelica-3rdparty/ExternalMedia>`_ (see its `releases page <https://github.com/modelica-3rdparty/ExternalMedia/releases/>`_).
